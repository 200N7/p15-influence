\# Dataset Provenance



All datasets included with P15 are synthetic project datasets created for algorithm development, testing and demonstration. They do not contain scraped, private or real social-media user data.



\## Included Datasets



| Dataset | Purpose | Provenance |

|---|---|---|

| `data/tiny.txt` | Small graph for basic loading and algorithm checks | Manually created synthetic test data |

| `data/communities.txt` | Small graph for community-analysis examples | Manually created synthetic test data |

| `data/normal.txt` | Normal social-network evaluation scenario | Manually designed synthetic project scenario |

| `data/shock.txt` | Viral/capacity-shock comparison scenario | Synthetic modification of the normal scenario |

| `data/stress.txt` | Large deterministic scalability scenario | Generated by `bench/generate\_stress.c` |



\## Stress Dataset



`data/stress.txt` contains:



&#x20;   500 users

&#x20;   2000 directed relationships



It can be regenerated offline using:



&#x20;   gcc -std=c11 -Wall -Wextra -Wpedantic bench/generate\_stress.c -o generate\_stress

&#x20;   ./generate\_stress > data/stress.txt



The generator is deterministic, allowing the same stress dataset to be reproduced for repeated evaluation.



\## Data Format



Each relationship uses:



&#x20;   source\_user target\_user probability



where:



&#x20;   0 < probability <= 1



\## Privacy and Licensing



Because the included datasets are synthetic project-created data, no third-party dataset license or personal-user-data permission is required.



The datasets are intended only for demonstration, testing and academic evaluation of the algorithms in this repository.
